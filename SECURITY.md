# Security

## Reporting a vulnerability
Please do not open a public issue. Use GitHub's private reporting instead: the **Security** tab of this repository,
then **Report a vulnerability**. Describe what is affected, how to reproduce it, and what an attacker could do with it.
You will get an answer when I have looked at it; this is a personal project with no guaranteed response time.

## Supported versions
The latest release and the `main` branch.

## Scope
The README's "Security" section describes what athenafs exposes, the privileges its containers need, the guards in place,
and what stays the operator's responsibility (what is downloaded and seeded, under whose IP address). Reports about
these are welcome, as are reports about the web page, the API, the SMB share and the patches to Distribyted.
